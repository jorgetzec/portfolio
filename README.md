## Live Site

### [jorgetzec.github.io/portfolio](https://jorgetzec.github.io/portfolio/)

A minimalist, code-inspired portfolio built with **React, TypeScript, and TailwindCSS**. Features include an animated DNA helix in the hero section, project categorization, and interactive project detail modals.

## Tech Stack

| Layer | Technology |
|-------|------------|
| **UI** | React 19 + TypeScript |
| **Bundler** | Vite |
| **Styling** | TailwindCSS |
| **Animations** | Framer Motion |
| **Lightbox** | Yet Another React Lightbox |

## Development

```bash
npm install      # Install dependencies
npm run dev      # Start dev server
npm run build    # Type-check + production build
npm run lint     # Lint with ESLint
npm run preview  # Preview production build
```
